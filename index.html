Features

অ্যাপে যা যা পাচ্ছেন

খেলতে আসুন, বাকি ব্যবস্থা আমাদের।

রিয়েলটাইম স্লট বুকিং

খালি ও বুক হওয়া স্লট সাথে সাথে দেখুন, এক বা একাধিক ঘণ্টা সিলেক্ট করুন।

সহজ পেমেন্ট

বিকাশ, নগদ, উপায়, রকেট, কার্ড অথবা টার্ফে নগদ, যেটা সুবিধা।

টুর্নামেন্ট নিবন্ধন

ফ্রেন্ডলি ম্যাচ ও টুর্নামেন্টে দল নিয়ে অংশ নিন, ট্রফি জিতুন।

মেম্বারশিপ ও কুপন

বেশি খেললে বেশি ছাড়। কুপন কোড ও মেম্বারশিপ ডিসকাউন্ট সরাসরি অ্যাপে।

নোটিফিকেশন

আজ রাতের স্লট, অফার ও নতুন টুর্নামেন্টের খবর সবার আগে পান।

লাইভ সাপোর্ট চ্যাট

কোনো সমস্যায় সরাসরি আমাদের সাপোর্ট টিমের সাথে চ্যাট করুন।

Install Guide

৪ ধাপে অ্যাপ ইনস্টল

প্লে স্টোরের বাইরে থেকে ইনস্টল করছেন, তাই প্রথমবার এই ধাপগুলো দরকার হতে পারে।

APK ডাউনলোড করুন

উপরের “অ্যাপ ডাউনলোড” বাটনে ট্যাপ করুন। ব্রাউজার ফাইলটি সেভ করবে।

ফাইলটি খুলুন

ডাউনলোড শেষ হলে নোটিফিকেশন বা Downloads ফোল্ডার থেকে GreenTurf.apk ওপেন করুন।

অনুমতি দিন

“Install unknown apps” চাইলে Settings এ গিয়ে আপনার ব্রাউজারের জন্য অনুমতি চালু করুন।

ইনস্টল ও খেলা শুরু

Install ট্যাপ করুন, অ্যাপ খুলে সাইন ইন করুন আর প্রথম স্লট বুক করুন।

নিরাপত্তার জন্য শুধু এই অফিসিয়াল পেজ থেকেই অ্যাপ ডাউনলোড করুন। অন্য কোনো সোর্স থেকে পাঠানো ফাইল ইনস্টল করবেন না।
FAQ

সাধারণ প্রশ্ন

অ্যাপটি কি ফ্রি?

হ্যাঁ, অ্যাপ ডাউনলোড ও ব্যবহার সম্পূর্ণ ফ্রি। আপনি শুধু বুক করা স্লটের জন্য টার্ফের নির্ধারিত ফি দেবেন।

iPhone এ কি পাওয়া যাবে?

এই APK শুধু Android ফোনের জন্য। iPhone ব্যবহারকারীরা আমাদের ওয়েবসাইট থেকে একই সুবিধা পাবেন।

ইনস্টল করতে গিয়ে ব্লক দেখাচ্ছে, কী করব?

Settings → Security (বা Apps) → Install unknown apps এ গিয়ে আপনার ব্রাউজারের জন্য অনুমতি দিন, তারপর আবার ফাইলটি ওপেন করুন।

পেমেন্ট করার পর কনফার্মেশন কত সময়ে আসে?

কার্ড বা অনলাইন পেমেন্টে সাথে সাথে। মোবাইল ব্যাংকিংয়ে Transaction ID যাচাইয়ের পর প্রোফাইলে স্ট্যাটাস আপডেট হয়।

সমস্যা হলে কোথায় যোগাযোগ করব?

অ্যাপের সাপোর্ট চ্যাট বা নিচের যোগাযোগ সেকশনের নম্বরে কল করুন।

আপনার দল প্রস্তুত?

আজ রাতের স্লট দ্রুত ফুরিয়ে যায়। অ্যাপ নিয়ে এখনই বুক করুন।
